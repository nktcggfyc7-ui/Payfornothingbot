# Pay For Nothing Bot

Готовый Telegram-бот для мемного и ироничного сценария "платишь за ничего".

## Что делает бот

- честно говорит, что пользователь не получает товар, услугу или выгоду
- предлагает три уровня nothing: `100 ₽`, `500 ₽`, `1000 ₽`
- принимает подтверждение оплаты вручную через чек, скриншот или текст
- отправляет заявку админу на подтверждение
- после подтверждения добавляет пользователя в статистику
- ведет личный кабинет, топ легенд, список профи и историю пользователей

## Структура проекта

- `main.py` — основной файл бота
- `config.json` — рабочая конфигурация
- `config.example.json` — шаблон конфигурации
- `run_bot.ps1` — запуск в PowerShell
- `run_bot.bat` — запуск двойным кликом в Windows
- `package_delivery.ps1` — создание ZIP-архива для передачи
- `Dockerfile` — готовая сборка для деплоя на Koyeb
- `render.yaml` — готовая конфигурация для Render
- `tests/test_storage.py` — локальные тесты хранилища и сценария оплаты
- `data/` — база SQLite создается автоматически после первого запуска

## Поток пользователя

1. Пользователь нажимает `/start`.
2. Бот показывает честное описание: здесь платят за ничего.
3. Пользователь открывает `Купить ничего` или `Магазин`.
4. Выбирает один из трех уровней nothing.
5. Бот показывает номер карты.
6. Пользователь переводит деньги.
7. Нажимает `Я платил` и отправляет скриншот, фото чека, документ или текст.
8. Администратор вручную подтверждает или отклоняет заявку.
9. После подтверждения пользователь попадает в статистику и личный кабинет.

## Что хранится по каждому пользователю

- дата первого входа
- username и имя
- количество подтвержденных оплат
- общая сумма переводов
- максимальный уровень nothing
- место в рейтинге
- количество приглашенных друзей
- последняя заявка и ее статус

## Статистика

Кнопка `Статистика` показывает:

- общее количество пользователей
- количество оплативших пользователей
- количество подтвержденных оплат
- общую сумму оплат
- топ пользователей по сумме
- дату последнего обновления

Плановое обновление статистики выполняется каждые 24 часа.

## Первый вход администратора

После запуска первый администратор может выдать себе права через:

```text
/grant_admin <секрет_из_config.json>
```

После этого становятся доступны кнопки `Админка` и `Очередь оплат`.

## Запуск

Нужен Python 3.11+.

Бот поддерживает запуск через переменные окружения:

- `PAYFORNOTHING_BOT_TOKEN`
- `PAYFORNOTHING_CARD_NUMBER`
- `PAYFORNOTHING_ADMIN_SECRET`
- `PAYFORNOTHING_SUPPORT_CONTACT`

Это удобно для сервера и безопаснее, чем хранить секреты в GitHub.

Проверка проекта:

```powershell
.\run_bot.ps1 --check
```

Запуск бота:

```powershell
.\run_bot.ps1
```

Или двойной клик по:

```text
run_bot.bat
```

## Бесплатный деплой на Koyeb

Почему выбран именно Koyeb:

- у Koyeb есть `1 free web Service` в бесплатном тарифе
- есть официальный деплой из GitHub
- платформа поддерживает и web services, и workers

См. официальные материалы:

- [Koyeb Pricing FAQ](https://www.koyeb.com/docs/faqs/pricing)
- [Koyeb Deploy with GitHub](https://www.koyeb.com/docs/build-and-deploy/deploy-with-git)
- [Koyeb Services](https://www.koyeb.com/docs/reference/services)

Как развернуть:

1. Загрузить этот проект в GitHub-репозиторий.
2. Создать аккаунт на Koyeb.
3. В Koyeb выбрать `Create Web Service`.
4. Подключить GitHub и выбрать репозиторий.
5. В качестве источника использовать `Dockerfile`.
6. В переменных окружения Koyeb задать:
   - `PAYFORNOTHING_BOT_TOKEN`
   - `PAYFORNOTHING_CARD_NUMBER`
   - `PAYFORNOTHING_ADMIN_SECRET`
7. Убедиться, что переменные и конфиг корректны.
8. Запустить деплой.

Бот уже под это подготовлен:

- сам поднимает health endpoint
- слушает порт из переменной `PORT`
- отвечает `200 OK` на `/healthz`

## Простой деплой на Render

В проект уже добавлен `render.yaml`, поэтому можно использовать репозиторий как готовую заготовку для Render.

Что нужно в Render:

1. Создать `Web Service`
2. Выбрать репозиторий
3. Использовать конфигурацию из `render.yaml`
4. Добавить секрет `PAYFORNOTHING_BOT_TOKEN`

Важно:

- на `Render Free` сервис засыпает без входящего трафика
- локальная файловая система там временная, поэтому SQLite на free-режиме не считается постоянным хранилищем

## Важное замечание по Telegram

По актуальной официальной документации Telegram цифровые товары и услуги внутри ботов должны оплачиваться через Telegram Stars:

- [Bot Payments API for Digital Goods and Services](https://core.telegram.org/bots/payments-stars)

Этот проект реализует именно тот сценарий, который был запрошен: ручной перевод на карту и ручное подтверждение администратором. Но использовать его стоит с учетом правил платформы.
